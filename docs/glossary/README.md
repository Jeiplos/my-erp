# 词汇表 (glossary)

本目录用于解释 my-erp 文档与讨论中出现的专业词汇，避免「术语看不懂导致设计意图读不懂」。

## 怎么用这个目录

- 每个词条一个独立文件，文件名用小写英文（如 `aggregate.md` 对应「聚合 / 聚合根」）。
- 词条互相引用时使用相对链接，读到一个不认识的词可以直接跳过去。
- 每个词条聚焦四件事：**一句话定义** → **具体例子** → **在本项目里怎么用** → **常见误解**。
- 只解释本项目真正会用到的词，不追求做成通用术语大全。

| 词条 | 一句话说明 |

## 建议阅读顺序

如果是第一次接触这些概念，按这条线读最顺（它们之间有依赖关系）：

```
领域模型 → 实体 / 值对象 → 聚合（边界）→ 仓储（怎么存取）→ 业务不变式（要守住什么）
   ↓
分层架构 → 分层职责 → 应用服务（谁编排）→ 依赖方向（谁依赖谁）
   ↓
主数据（本项目第一个模块）→ MVP（先做多少）→ 验收标准（怎么算做完）→ 中间件（后续迭代）
```

其余词条（限界上下文、防腐层、领域服务、DTO、贫血/充血、库存语义）是查漏补缺性质的，
遇到具体设计问题再回头翻即可。

## 维护约定

- 新增词条时，请同时在**索引**和 `docs/README.md` 中登记，避免出现孤儿文件。
- 术语的中文译名以本表为准，代码里的类名、包名一律用英文，两者通过词条对应起来。
- 词条里的「在本项目里怎么用」一节会随项目迭代更新，
  若某处描述与代码现状不符，**以代码为准并同步修正文档**。
