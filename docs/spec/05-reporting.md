# reporting 服务规格

## 1. 职责

提供只读报表查询，聚合 masterdata、inventory、sales、purchasing 的数据，服务于运营、财务、管理层的查询需求。

核心目标：

- 只读，不产生任何写操作
- 纯 CRUD 查询，不做复杂计算
- 支持分页、过滤、排序
- 统一时间口径，避免歧义
- 与业务服务解耦，失败不影响业务

## 2. 边界与定位

### 2.1 只读原则

- reporting 不写任何业务数据
- 不修改库存、订单、主数据
- 不触发任何状态流转
- 所有接口都是查询

### 2.2 数据来源

MVP 阶段：

- 通过调用各业务服务的查询能力聚合数据
- 或直接读取各服务 schema 的只读副本
- 不建立独立报表库

未来可扩展：

- 建立独立报表库
- 通过 CDC / 消息同步
- 引入 OLAP / 数仓

### 2.3 时间口径

报表涉及多个时间字段，必须明确口径，避免歧义。

| 时间字段 | 含义 | 适用报表 |
|---|---|---|
| created_at | 创建时间 | 默认过滤口径 |
| confirmed_at | 确认时间 | 订单确认统计 |
| shipped_at | 发货时间 | 销售发货统计 |
| received_at | 收货时间 | 采购收货统计 |
| cancelled_at | 取消时间 | 取消统计 |

规则：

- 默认按 `created_at` 过滤
- 可按需切换为 `confirmed_at`、`shipped_at`、`received_at`
- 时间统一 UTC，ISO-8601
- 时间范围左闭右开 `[start, end)`
- 文档保留两个时间口径，实现可先只做 created_at

## 3. 报表清单

### 3.1 库存余额报表

用途：查看各 SKU 在各仓库的现存量、预占量、可用量。

| 字段 | 说明 |
|---|---|
| sku | 商品 SKU |
| product_name | 商品名称 |
| warehouse_code | 仓库编码 |
| on_hand_qty | 现存量 |
| reserved_qty | 预占量 |
| available_qty | 可用量 |
| updated_at | 最后更新时间 |

过滤：

- SKU
- 仓库
- 可用量范围
- 仅显示有库存

排序：

- SKU
- 可用量
- 更新时间

### 3.2 库存流水报表

用途：追溯每一次库存变动，用于对账、审计、分析。

| 字段 | 说明 |
|---|---|
| transaction_no | 流水号 |
| type | 流水类型 |
| sku | 商品 SKU |
| warehouse_code | 仓库编码 |
| on_hand_delta | 现存量变动 |
| reserved_delta | 预占量变动 |
| on_hand_after | 变动后现存量 |
| reserved_after | 变动后预占量 |
| source_type | 来源类型 |
| source_no | 来源单号 |
| source_line_no | 来源行号 |
| created_at | 发生时间 |
| created_by | 操作人 |

过滤：

- SKU
- 仓库
- 流水类型
- 来源类型
- 来源单号
- 时间范围

排序：

- 发生时间倒序
- 流水号

### 3.3 销售订单统计

用途：查看销售订单数量、金额、状态分布。

| 字段 | 说明 |
|---|---|
| order_no | 订单号 |
| customer_code | 客户编码 |
| customer_name | 客户名称 |
| status | 订单状态 |
| total_qty | 总数量 |
| shipped_qty | 已发数量 |
| total_amount | 总金额，字段预留 |
| currency | 币种，字段预留 |
| created_at | 创建时间 |
| confirmed_at | 确认时间 |
| shipped_at | 发货时间 |

汇总维度：

- 按状态汇总订单数
- 按客户汇总订单数
- 按时间汇总订单数
- 按 SKU 汇总销售数量

过滤：

- 客户
- 状态
- 时间范围（默认 created_at）
- SKU

排序：

- 创建时间倒序
- 金额倒序

### 3.4 采购订单统计

用途：查看采购订单数量、金额、状态分布。

| 字段 | 说明 |
|---|---|
| order_no | 采购订单号 |
| supplier_code | 供应商编码 |
| supplier_name | 供应商名称 |
| status | 订单状态 |
| total_qty | 总数量 |
| received_qty | 已收数量 |
| total_amount | 总金额，字段预留 |
| currency | 币种，字段预留 |
| created_at | 创建时间 |
| confirmed_at | 确认时间 |
| received_at | 收货时间 |

汇总维度：

- 按状态汇总订单数
- 按供应商汇总订单数
- 按时间汇总订单数
- 按 SKU 汇总采购数量

过滤：

- 供应商
- 状态
- 时间范围（默认 created_at）
- SKU

排序：

- 创建时间倒序
- 金额倒序

### 3.5 商品销售排行

用途：查看畅销商品、滞销商品。

| 字段 | 说明 |
|---|---|
| sku | 商品 SKU |
| product_name | 商品名称 |
| total_ordered_qty | 总订购数量 |
| total_shipped_qty | 总发货数量 |
| total_amount | 总金额，字段预留 |

过滤：

- 时间范围
- 客户
- 仓库

排序：

- 发货数量倒序
- 金额倒序

### 3.6 库存变动趋势

用途：查看某段时间内库存的入、出、净变动。

| 字段 | 说明 |
|---|---|
| date | 日期 |
| sku | 商品 SKU |
| inbound_qty | 入库数量 |
| outbound_qty | 出库数量 |
| net_change | 净变动 |

过滤：

- SKU
- 仓库
- 时间范围

排序：

- 日期升序

## 4. 业务规则

### 4.1 查询规则

- 所有查询必须分页
- 默认每页 20，最大 200
- 排序字段白名单，防止注入
- 时间范围必填或默认最近 30 天
- 过滤条件可组合

### 4.2 数据一致性

- reporting 不保证强一致
- 允许秒级延迟
- 文档说明最终一致
- 不做分布式事务

### 4.3 权限

- MVP 不做鉴权
- 未来可加数据权限、字段脱敏

### 4.4 性能

- 查询走只读副本或索引
- 大范围查询限制时间跨度
- 导出功能后续再说

## 5. 业务能力

### 5.1 库存报表

- `listInventoryBalances(query)`  
  分页查询库存余额。入参：SKU、仓库、可用量范围、分页参数。  
  返回：SKU、商品名称、仓库、现存量、预占量、可用量、更新时间。

- `listInventoryTransactions(query)`  
  分页查询库存流水。入参：SKU、仓库、流水类型、来源类型、来源单号、时间范围、分页参数。  
  返回：流水号、类型、SKU、仓库、变动数量、变动后数量、来源、时间、操作人。

- `getInventoryTransaction(transactionNo)`  
  查询单条流水详情。

### 5.2 销售报表

- `listSalesOrders(query)`  
  分页查询销售订单统计。入参：客户、状态、时间范围、SKU、分页参数。  
  返回：订单号、客户、状态、总数量、已发数量、金额、时间。

- `getSalesOrderSummary(query)`  
  销售订单汇总。入参：客户、状态、时间范围。  
  返回：订单总数、总数量、总金额、按状态分组。

- `listSalesByProduct(query)`  
  商品销售排行。入参：时间范围、客户、仓库、分页参数。  
  返回：SKU、商品名称、订购数量、发货数量、金额。

- `listSalesByCustomer(query)`  
  客户销售汇总。入参：时间范围、分页参数。  
  返回：客户编码、客户名称、订单数、总数量、总金额。

### 5.3 采购报表

- `listPurchaseOrders(query)`  
  分页查询采购订单统计。入参：供应商、状态、时间范围、SKU、分页参数。  
  返回：订单号、供应商、状态、总数量、已收数量、金额、时间。

- `getPurchaseOrderSummary(query)`  
  采购订单汇总。入参：供应商、状态、时间范围。  
  返回：订单总数、总数量、总金额、按状态分组。

- `listPurchaseByProduct(query)`  
  商品采购汇总。入参：时间范围、供应商、分页参数。  
  返回：SKU、商品名称、订购数量、收货数量、金额。

- `listPurchaseBySupplier(query)`  
  供应商采购汇总。入参：时间范围、分页参数。  
  返回：供应商编码、供应商名称、订单数、总数量、总金额。

### 5.4 趋势报表

- `listInventoryTrend(query)`  
  库存变动趋势。入参：SKU、仓库、时间范围、分页参数。  
  返回：日期、SKU、入库数量、出库数量、净变动。

- `listOrderTrend(query)`  
  订单趋势。入参：类型（销售/采购）、时间范围、分页参数。  
  返回：日期、订单数、总数量、总金额。

## 6. 验收场景

1. 查询库存余额，分页正确
2. 按 SKU 过滤库存余额，结果正确
3. 查询库存流水，按时间范围过滤，结果正确
4. 查询库存流水，按来源单号过滤，能追溯到订单
5. 查询销售订单统计，按状态分组正确
6. 查询销售订单统计，时间口径切换正确
7. 查询商品销售排行，排序正确
8. 查询采购订单统计，按供应商分组正确
9. 查询库存变动趋势，入库出库数量正确
10. 分页超过最大页大小，自动限制为 200
11. 排序字段不在白名单，失败，返回明确错误
12. 时间范围缺失，默认最近 30 天
13. 查询无数据，返回空列表，不报错
14. 业务服务不可用，reporting 返回明确错误，不影响业务
15. 报表数据与业务数据对账一致（允许秒级延迟）

## 7. 非目标

- 不做写操作
- 不做独立报表库
- 不做 CDC 同步
- 不做 OLAP
- 不做导出 CSV/Excel（后续再说）
- 不做图表渲染
- 不做实时大屏
- 不做权限与脱敏
- 不做分布式事务
- 不做成本、毛利、存货估值报表（依赖成本核算，一期不做）
