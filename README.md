# my-erp

一个用 Java 复现的简单 ERP 示例服务，配套文档与可运行的代码。

> 当前状态：**仓库骨架已初始化**。业务代码尚未开始，目录结构、技术选型和开发路线见下文。

## 这是什么

本仓库的目标是用尽可能小、但结构正确的 Java 服务，把 ERP 的核心链路跑通一遍，
既可以当作学习样例，也可以当作后续真实项目的起手模板。

设计原则：

- **小而完整**：只实现必要的领域概念，但分层、分层职责、错误处理、测试都要真实可用。
- **文档与代码同步**：每一步实现都对应 `docs/` 下的设计说明，不写“以后补”的注释。
- **可运行优先**：任何一次提交后，`mvn test` 都应该是绿的。

## 计划实现的业务模块

按依赖顺序推进，每个模块完成后再进入下一个：

1. **主数据 (masterdata)** — 商品与客户/供应商的增删改查，是其他模块的前置。
2. **库存 (inventory)** — 入库、出库、库存余额查询，保证不出现负库存。
3. **销售 (sales)** — 销售订单创建/确认/发货，发货时扣减库存。
4. **采购 (purchasing)** — 采购订单与收货，收货时增加库存。
5. **报表 (reporting)** — 库存流水、订单统计等只读查询。

## 本地开发

前置条件（本机已满足）：

```powershell
java -version    # 需要 21
mvn -v           # 需要 3.9+
```

当前尚无 `pom.xml`，因此还没有可执行的构建命令；加入 Maven 工程后，本节会更新为：

```powershell
mvn test         # 运行测试
mvn spring-boot:run   # 启动服务
```
